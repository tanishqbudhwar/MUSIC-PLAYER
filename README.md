# 🎵 Music Player

A modern and responsive web-based music player built using **HTML**, **CSS**, **JavaScript**, **Bootstrap**, and **jQuery**. This project allows users to play, pause, skip tracks, adjust volume, and control music playback through an interactive user interface.

## 🚀 Features

* ▶️ Play and Pause songs
* ⏮️ Previous song button
* ⏭️ Next song button
* 🎚️ Seek bar to control playback
* 🔊 Volume control slider
* ⏱️ Real-time song progress
* 🎵 Dynamic song title display
* 📱 Responsive design for desktop and mobile devices
* 🎨 Clean and modern user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Bootstrap 5
* jQuery
